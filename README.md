# ContentFlow AI 🚀

An AI-powered carousel creation tool that helps users create, customize, preview, and export professional social media carousel slides.

🔗 **Live Demo:** https://contentflow-ai-lilac.vercel.app/

---

## ✨ Features

- 📝 **Editable Carousel Content**  
  Customize headlines, body text, and key takeaways for every slide.

- 🎨 **Multiple Visual Directions**  
  Choose different visual styles and themes to change the appearance of your carousel.

- 👀 **Live Preview**  
  Instantly preview your carousel slides while editing.

- 🔢 **Slide Navigation**  
  Navigate between slides using slide controls and interactive navigation.

- 👉 **Interactive Swipe Navigation**  
  Move through the carousel using the **Swipe →** interaction.

- 🖼️ **Image Export**  
  Export carousel slides as images.

- 📄 **PDF Export**  
  Export the complete carousel as a PDF.

- 📦 **ZIP Export Support**  
  Download multiple carousel slides together.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Muskan21-creater/contentflow-ai.git
```

### 2. Navigate to the project directory

```bash
cd contentflow-ai
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed by Vite in your browser.

---

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

5. Export the carousel as images or a PDF.
